# Sprint 1 smoke checklist

1. Create a new test with radio/checkbox/input questions.
2. Pass test and open `/attempts/{id}`.
3. Verify result badges and per-question statuses.
4. Move test to trash, then open `/attempts/{id}` again.
5. Delete test permanently from trash, open same `/attempts/{id}`.
6. Verify selected answers and correct options are still rendered.
7. Verify login/register/logout still work.
8. Verify create/delete/restore actions return user-friendly error pages on DB failures.
